# Lacanian gap v1 — наше понимание (external-реферат)

**Это версия нашего понимания, не самой идеи** — концепт external, владелец смысла — первоисточник ([[CON-concept-origin]]).

Рабочее понимание в системе: конститутивный разрыв/нехватка (béance, manque) как структурный элемент, а не дефект, подлежащий устранению. Концепт кочует по контекстам вольта — появляется в богословии и других темах, включается в разные механизмы; в графе это один узел, участвующий во множестве суждений.

**Проверка:** данный реферат сверяется с `primary_source`, а не с внутренним спором. Уточнение понимания = новая версия этого файла.

**Использование в системе:** образец external-концепта; источник инженерной рифмы для [[CON-gap]] — зазор знания и воли как удерживаемая конструкция. Узел живёт в рабочем вольте философии, не в мета-вольте (переезд 2026-09-04).
